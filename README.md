# CodeAlpha_Calculator
A simple, responsive web calculator built with **HTML**, **CSS**, and **JavaScript**. It performs basic arithmetic operations with a clean and modern interface, and runs entirely in the browser without any frameworks or libraries.

## Features

- Basic arithmetic operations: addition, subtraction, multiplication, division, module
- Clear (AC) and delete (DEL) functions  
- Responsive design that works on mobile and desktop  
- Pure front-end implementation (no backend, no frameworks)

## Technologies Used

- **HTML5** – Structure of the calculator  
- **CSS3** – Styling, layout, and responsiveness  
- **JavaScript (ES6+)** – Logic for calculations, button interactions & keyboard support 

## Project Structure

```text
.
├── index.html        # Main HTML file
├── style.css         # Styles for the calculator
├── script.js         # JavaScript logic
└── README.md         # Project documentation
```

## How It Works (Brief)

- The calculator UI is built using semantic HTML elements (buttons, display input).  
- CSS handles layout (often with Flexbox/Grid), colors, and responsive behavior.  
- JavaScript listens for button clicks, updates the display, keyboard support & evaluates expressions safely to show results.
